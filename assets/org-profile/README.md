# ShopManager AI

Open-source and hosted AI tooling that connects Claude, ChatGPT, Codex, Cursor
and compatible MCP clients to Shopify.

## Projects

**[shopify-mcp](https://github.com/shopmanagerai/shopify-mcp)** - a free,
open-source Shopify MCP server. 122 read-only tools for Shopify themes,
Liquid, products, collections, content, store configuration and diagnostics.
Self-hostable, Apache-2.0, and read-only against Shopify by design.
